        Product & Disaster-Recovery Architecture
        
Intelligent Analyst & Offline Resilience Blueprint

        

          Built as a fixed-viewport native-style application with zero page scrolling, millisecond local auto-save, and plain-text Notepad (`.txt`) disaster recovery.
        

      


      

        

          
01. Zero-Click Auto-Save

          

            Every buy-in, `+1` rebuy, or chip edit immediately writes to localStorage. Accidental clicks on Save or End Session are guarded by confirmation modals.
          

        

        

          
02. Notepad (.TXT) Ledger

          

            One tap exports a formatted `.txt` file showing every player's buy-in count (`1x`, `2x`, `3x`), dollar stacks, and who pays whom—readable in any Notepad app without internet.
          

        

        

          
03. 100% Offline Execution

          

            All settlement math (`Math.round(amount * 100)`) and minimum-edge graph matching run 100% locally in the browser with zero external API dependencies.
